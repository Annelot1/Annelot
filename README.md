Mijn samenvattingen van de artikelen:

Introduction HTML & CSS:

Deze introductie gaat over de basis van het maken van websites. Een website bestaat voornamelijk uit drie onderdelen: HTML, CSS en JavaScript. HTML gebruik je om de inhoud en structuur van een webpagina te maken, bijvoorbeeld teksten, afbeeldingen, titels en links. CSS gebruik je vervolgens om te bepalen hoe deze onderdelen eruitzien, zoals kleuren, lettertypes, afmetingen en de positie van elementen. JavaScript wordt gebruikt om een website interactief te maken.
De tutorial richt zich vooral op HTML en CSS. Het doel is om eerst goed te begrijpen hoe deze basistechnieken werken voordat je met ingewikkeldere technieken of frameworks begint. Je leert niet alleen welke code je moet gebruiken, maar ook hoe verschillende onderdelen van een webpagina met elkaar samenwerken.
Een belangrijk onderdeel is zelf oefenen. Door code zelf te typen in een teksteditor en het resultaat steeds in de browser te bekijken, zie je direct wat veranderingen in je code doen. Ook wordt benadrukt dat fouten maken normaal is bij programmeren. Door dingen uit te proberen, fouten op te zoeken en je code aan te passen, krijg je steeds meer inzicht in hoe websites zijn opgebouwd.

Basic Web Pages:

Dit hoofdstuk gaat over de basis van HTML en hoe je daarmee een eenvoudige webpagina opbouwt. HTML bepaalt de inhoud en structuur van een website. Je gebruikt hiervoor verschillende HTML-tags, die de browser vertellen wat bijvoorbeeld een titel, tekst of lijst is. 
Elke HTML-pagina heeft een vaste basisstructuur. In de head staat informatie over de pagina die niet direct zichtbaar is, zoals de paginatitel. In de body staat alles wat de bezoeker daadwerkelijk op de website ziet. Het is belangrijk dat HTML-elementen op de juiste manier in elkaar worden geplaatst (nested) en netjes worden ingesprongen, zodat de code overzichtelijk blijft. 
Je leert verschillende veelgebruikte HTML-elementen kennen, zoals h1 tot h6 voor koppen, p voor paragrafen, ul en ol voor lijsten en li voor de onderdelen van een lijst. Met em kun je tekst extra nadruk geven en met strong geef je tekst een sterkere nadruk. Ook komen br voor een regelafbreking en hr voor een scheiding tussen stukken content aan bod. 
Een belangrijk verschil is dat HTML gaat over de betekenis en structuur van de inhoud, terwijl CSS later wordt gebruikt voor de vormgeving. Je moet HTML dus niet gebruiken om bijvoorbeeld kleuren, afstanden of andere visuele eigenschappen te bepalen. Eerst bouw je de inhoud en structuur met HTML en daarna bepaal je met CSS hoe deze eruit komt te zien. 

CSS:

Waar HTML wordt gebruikt voor de inhoud en structuur van een website, gebruik je CSS om te bepalen hoe de website eruitziet. Met CSS kun je bijvoorbeeld kleuren, lettertypes, tekstgroottes, achtergronden en uitlijning aanpassen. 
CSS wordt meestal in een apart .css-bestand geschreven. Dit bestand koppel je vervolgens aan je HTML-bestand met een link in de head. Hierdoor kun je één stylesheet gebruiken voor meerdere pagina's. Als je vervolgens iets in het CSS-bestand verandert, wordt die verandering automatisch toegepast op alle gekoppelde pagina's. Dit zorgt ervoor dat een website een consistente vormgeving heeft. 
Een CSS-regel bestaat uit een selector, een property en een value. De selector bepaalt welk HTML-element je wilt aanpassen. De property bepaalt wat je wilt veranderen en de value geeft aan hoe dit eruit moet zien. Hiermee verander je de grootte en kleur van alle h1-koppen. Je leert daarnaast eigenschappen zoals background-color, font-family, font-weight, text-align en text-decoration. Voor afmetingen kun je bijvoorbeeld px of em gebruiken. 
Tot slot wordt de cascade uitgelegd. Dit betekent dat meerdere CSS-regels invloed kunnen hebben op hetzelfde element. Sommige regels krijgen daarbij voorrang op andere. Het hoofdstuk adviseert vooral om externe CSS-bestanden te gebruiken en inline CSS zoveel mogelijk te vermijden, omdat externe stylesheets overzichtelijker en makkelijker aan te passen zijn. 

Structuring Content with HTML:

Dit onderdeel van MDN gaat over hoe je met HTML de inhoud en structuur van een website opbouwt. HTML geeft niet alleen aan wat er op een pagina staat, maar ook wat de betekenis van de verschillende onderdelen is. Een goede HTML-structuur is belangrijk voor de leesbaarheid van je code, maar ook voor toegankelijkheid en zoekmachines. 
Je begint met de basis van HTML, zoals elementen, tags en attributen. Daarna leer je hoe een HTML-document is opgebouwd. In de head staat informatie die niet direct op de pagina zichtbaar is, zoals de titel, metadata en koppelingen naar CSS. De zichtbare inhoud van de website komt in de body. 
Vervolgens komen verschillende manieren aan bod om content te structureren. Denk aan koppen en paragrafen, lijsten, links en afbeeldingen. Je leert ook dat je specifieke HTML-elementen kunt gebruiken om grotere onderdelen van een website aan te geven, zoals een header, navigatiemenu en hoofdcontent. Hierdoor krijgt de pagina een duidelijke en logische indeling. 
Daarnaast behandelt het onderdeel afbeeldingen, video, audio, tabellen, formulieren en knoppen. Bij afbeeldingen leer je bijvoorbeeld hoe je img gebruikt en bij formulieren hoe je informatie van een gebruiker kunt verzamelen. Ook wordt aandacht besteed aan het vinden en oplossen van fouten in je HTML-code. 

MDN Web Docs:

Is een grote online informatiebron voor iedereen die wil leren hoe je websites maakt. Je vindt er uitleg, voorbeelden en oefeningen over de belangrijkste programmeertalen en technieken voor het web.
De website behandelt vooral HTML, CSS en JavaScript:
* HTML gebruik je om de inhoud en structuur van een website te maken.
* CSS gebruik je voor de vormgeving, zoals kleuren, lettertypes, afstanden en layouts.
* JavaScript zorgt voor interactie en functionaliteiten, bijvoorbeeld knoppen, menu’s en animaties.
MDN bevat zowel informatie voor beginners als gevorderden. Als beginner kun je de onderdelen stap voor stap volgen om te leren hoe een website wordt opgebouwd. Daarnaast kun je MDN gebruiken als naslagwerk wanneer je tijdens het programmeren wilt opzoeken hoe een bepaalde HTML-tag, CSS-eigenschap of JavaScript-functie werkt.
Er wordt ook veel aandacht besteed aan toegankelijkheid, responsive websites en goede manieren van programmeren, zodat websites op verschillende apparaten werken en voor zoveel mogelijk mensen bruikbaar zijn.

Het huiswerk na deze deep dive was om vragen te beantwoorden die ik had van te voren:

1. Waarom is het belangrijk om HTML-elementen op de juiste manier in elkaar te plaatsen (nesten)?

Door HTML-elementen correct te nesten, begrijpt de browser beter hoe de onderdelen van de pagina bij elkaar horen. Het zorgt daarnaast voor overzichtelijke code en verkleint de kans op fouten in de structuur van je website.

3. Wat wordt bedoeld met de ‘cascade’ in CSS en waarom is dit belangrijk? 

De cascade bepaalt welke CSS-regel voorrang krijgt wanneer meerdere regels invloed hebben op hetzelfde HTML-element. Dit is belangrijk omdat je anders soms een stijl aanpast, maar er niets lijkt te veranderen doordat een andere CSS-regel voorrang heeft.
